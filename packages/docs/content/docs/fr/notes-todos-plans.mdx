# Notes, todos et plans de projet

Chaque projet a son propre espace de brouillon pour les notes, une todo list et les plans enregistrés. Ils appartiennent au projet, pas à une session particulière, donc ils restent disponibles lorsque vous passez d’une session à l’autre. Retrouvez-les dans l’onglet **Contexte** de la barre latérale droite (un onglet dédié sur mobile).

## Notes

Une zone de notes libre pour tout ce que vous voulez retenir sur le projet. Elle s’enregistre toute seule pendant que vous tapez.

## Todos

Une checklist simple. Ajoutez des éléments, cochez-les, réordonnez-les par glisser-déposer et supprimez ceux qui sont terminés.

Chaque todo possède un menu **envoyer** pour la confier à l’agent :

- l’envoyer à la session actuelle
- démarrer une nouvelle session avec elle
- démarrer une nouvelle [session worktree](/worktrees/) avec elle (uniquement si le projet est un dépôt git)

## Plans

Un endroit pour conserver des plans plus longs sous forme de fichiers enregistrés. Vous pouvez :

- importer un plan depuis un fichier Markdown ou texte
- ouvrir un plan pour le lire dans le panneau latéral
- supprimer les plans dont vous n’avez plus besoin

Vous devriez revenir dans l’onglet Contexte avec votre note enregistrée, votre todo cochée ou votre plan listé — c’est le signe que l’action a réussi.

## Suppression et annulation

Supprimer une note, un plan ou un souvenir enregistré affiche un toast avec **Annuler** pendant quelques secondes. L'élément n'est définitivement supprimé qu'une fois ce délai écoulé.

## Agents

Les agents lisent et mettent à jour les mêmes notes, todos et plans via l'outil de connaissance du projet. Demandez à un agent de noter une décision, d'ajouter un todo, d'en cocher un ou de tenir un plan à jour, et le changement apparaît dans le panneau au moment où il se produit. Les notes créées par un agent sont marquées comme venant d'un agent. Quand un agent rédige un plan pour vous, il peut l'ouvrir devant vous : vous le lisez, commentez des lignes et l'envoyez à une session. Les plans sont de simples fichiers Markdown, les agents les lisent et les modifient donc comme n'importe quel autre fichier. Ils commencent un plan par une courte liste de ses étapes et cochent chacune à mesure qu'ils la réalisent, et un plan ouvert récupère les changements en quelques secondes, de sorte que son aperçu montre l'avancement du travail.

Un agent travaille sur le projet auquel sa session appartient, worktrees compris. Si un agent modifie une note ou un plan pendant que vous y écrivez, ce que vous tapez est enregistré par-dessus le changement de l'agent. Il est demandé aux agents d'envoyer le texte qu'ils ont lu avec toute note ou tout plan qu'ils remplacent entièrement ; s'il a changé depuis, l'écriture est refusée et l'agent le relit.

L'outil est activé par défaut. Désactivez-le dans **Settings → General → OpenChamber Tools** avec **Project knowledge tool**. Comme les autres outils OpenChamber, il n'est présent que lorsqu'OpenChamber exécute son propre serveur OpenCode, donc ni avec un serveur externe ni dans l'extension VS Code.
