# プロジェクト

プロジェクトは、OpenChamber が追跡するあなたのコンピューター上のフォルダです。通常は 1 つのコードベースです。プロジェクトを切り替えると、エージェントが作業するフォルダ、そのプロジェクトのセッション、設定も切り替わります。

## プロジェクトを追加する

プロジェクトは複数の場所から追加できます。

- コマンドパレットの **Add project** 項目
- セッションサイドバー上部の **+** ボタン
- ディレクトリを選ぶときのフォルダブラウザ

フォルダを指定すると、OpenChamber が記憶します。名前はフォルダ名から取られますが、後で変更できます。

## プロジェクトを切り替える

サイドバーからプロジェクトを選ぶとアクティブになります。セッション、Git、メモなどすべてが、開いているプロジェクトに追従します。

## プロジェクトを見分けやすくする

**Settings → Projects** を開くと、プロジェクトにカスタム名、色、アイコンを設定できます。OpenChamber はアイコンを自動で探します。[プロジェクトアイコン](/project-icons/) を参照してください。

> VS Code では、OpenChamber は開いているフォルダを常に唯一のプロジェクトとして使います。そのため追加や切り替えはありません。Projects 設定ページも表示されません。

## セッションをフォルダーにグループ化する

サイドバーの **Tree** ビューでセッションを右クリックし、**Move to folder** を選ぶとフォルダーに入れられ、**New folder...** を選ぶと新しいフォルダーを作れます。フォルダーはプロジェクトルートまたは 1 つの worktree に属し、フォルダーの行には名前変更と削除のボタンがあります。フォルダーを削除してもそのセッションは残り、プロジェクトに戻ります。

フォルダーは OpenChamber サーバーに保存されるため、同じサーバーに接続しているものはすべて同じフォルダーを表示します：そのサーバーにサインインした別のコンピューター、Web アプリ、電話です。1 つでの変更は、再読み込みなしに 1 秒以内に他方へ反映されます。サーバーごとに独自のフォルダーを持ちます。どのフォルダーが折りたたまれているかは各デバイスに残ります。

電話では Tree ビューでフォルダーを表示できますが、変更はできません。セッションの移動はデスクトップまたは Web アプリで行ってください。

フォルダーを各デバイスに保持していたバージョンから更新した後、デバイスが初めて接続すると、そのフォルダーはサーバーのフォルダーに追加されます。サーバーが既に持つフォルダーと同じ名前で同じ場所にあるフォルダーはそれに合流し、そのセッションも一緒に移動します；何も失われません。サーバーが既に分類したセッションは、サーバーのフォルダーに残ります。

セッションを削除するとそのフォルダーから取り除かれ、プロジェクトを閉じるとそのフォルダーは削除されます。VS Code ではフォルダーは拡張機能内に留まり、共有されません。

## プロジェクトの環境

プロジェクトのツールが direnv、devenv、Nix シェルから提供される場合、Git フック、ターミナル、[プロジェクトアクション](/ja/project-actions/)はそれらを自力では見つけられません。**設定 → プロジェクト** を開いてプロジェクトを選び、**環境** で次のいずれかを行います。

- このプロジェクトだけに必要な変数を追加する
- 変数を出力する **環境コマンド** を設定する（例: `direnv export json`、`devenv print-dev-env --json`）

コマンドはプロジェクトのフォルダで実行され、worktree ではその worktree 自身のフォルダで実行されます。前回の実行から数分たっていれば、コミットしたとき、ターミナルを開いたとき、アクションを実行したときに再実行され、**再実行** を押すとすぐに実行されます。プロジェクトを開いているだけでは実行されません。入力欄の下には、前回の実行で追加された変数の数か、失敗した理由が表示されます。失敗した実行では何も追加されず、Git とターミナルはそのまま動き続けます。

これらの変数は、**設定 → 一般 → 環境変数** の変数に加えて、Git、ターミナル、プロジェクトアクションに渡されます（[環境変数](/ja/environment/#opencodegitターミナル用の変数)を参照）。OpenCode はひとつのプロセスですべてのプロジェクトを扱うため、プロジェクトの変数は受け取りません。エージェントに必要なものは一般のリストに入れてください。

コマンドを設定できるのはあなただけです。リポジトリからは読み込まれないため、クローンしたリポジトリが OpenChamber に何かを実行させることはできません。
