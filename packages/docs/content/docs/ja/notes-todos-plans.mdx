# プロジェクトのメモ、Todo、計画

各プロジェクトには、メモ、Todo リスト、保存済み計画のための専用スペースがあります。これらは特定のセッションではなくプロジェクトに属するため、セッションを移動しても残ります。右サイドバーの **Context** タブ（モバイルでは専用タブ）で見つけられます。

## メモ

プロジェクトについて覚えておきたいことを自由に書けるメモ欄です。入力すると自動で保存されます。

## Todo

シンプルなチェックリストです。項目を追加し、チェックを付け、ドラッグで並び替え、完了したものを消去できます。

各 Todo には **send** メニューがあり、エージェントに渡せます。

- 現在のセッションに送る
- それを使って新しいセッションを開始する
- それを使って新しい [worktree セッション](/worktrees/) を開始する（プロジェクトが Git リポジトリの場合のみ）

## 計画

長めの計画を保存済みファイルとして置いておく場所です。次のことができます。

- Markdown またはテキストファイルから計画をインポートする
- 計画を開いてサイドパネルで読む
- 不要になった計画を削除する

メモが保存され、Todo がチェックされ、または計画が一覧に表示された状態で Context タブに戻れば、操作が反映されたことが分かります。

## 削除と元に戻す

メモ、計画、保存済みメモリを削除すると、数秒間 **元に戻す** 付きのトーストが表示されます。その時間が過ぎて初めて、エントリは完全に削除されます。

## エージェント

エージェントはプロジェクト知識ツールを通じて、同じメモ、Todo、計画を読み取り、更新します。エージェントに決定をメモさせたり、Todo を追加・完了させたり、計画を最新に保たせたりすると、変更はその場でパネルに表示されます。エージェントが作成したメモには、エージェントによるものだと印が付きます。エージェントがあなたのために計画を書くとき、それを目の前に開くことができ、そこで読んだり、行にコメントしたり、セッションに送ったりできます。計画はプレーンな Markdown ファイルなので、エージェントは他のファイルと同じように読み書きします。計画は短いステップのチェックリストから始め、実装しながら各項目にチェックを入れます。開いている計画は数秒以内に変更を取り込むため、プレビューで作業の進み具合が分かります。

エージェントは、そのセッションが属するプロジェクトで作業します（worktree を含む）。入力中にエージェントがメモや計画を変更した場合、あなたの入力がエージェントの変更より優先して保存されます。エージェントは、メモや計画を丸ごと置き換える際、読んだテキストを一緒に送るよう求められます。その後変更されていた場合、書き込みは拒否され、エージェントは読み直します。

このツールはデフォルトでオンです。**Settings → General → OpenChamber Tools** の **Project knowledge tool** でオフにできます。他の OpenChamber ツールと同様、OpenChamber が独自の OpenCode サーバーを実行している場合にのみ利用でき、外部サーバーや VS Code 拡張機能では使えません。
