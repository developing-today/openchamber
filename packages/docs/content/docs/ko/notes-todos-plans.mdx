# 프로젝트 메모, 할 일, 계획

각 프로젝트에는 노트, 할 일 목록, 저장된 계획을 위한 자체 작업 공간이 있습니다. 이들은 특정 세션이 아니라 프로젝트에 속하므로 세션 사이를 오가도 그대로 유지됩니다. 오른쪽 사이드바의 **Context** 탭(모바일에서는 전용 탭)에서 찾을 수 있습니다.

## Notes

프로젝트에 대해 기억하고 싶은 것을 자유롭게 적는 노트 상자입니다. 입력하는 동안 자동으로 저장됩니다.

## Todos

간단한 체크리스트입니다. 항목을 추가하고, 체크하고, 드래그로 순서를 바꾸고, 완료된 항목을 정리합니다.

각 할 일에는 에이전트에게 넘길 수 있는 **send** 메뉴가 있습니다.

- 현재 세션으로 보내기
- 그것으로 새 세션 시작
- 그것으로 새 [worktree 세션](/ko/worktrees/) 시작(프로젝트가 git 저장소일 때만 가능)

## Plans

더 긴 계획을 저장된 파일로 보관하는 공간입니다. 다음을 할 수 있습니다.

- Markdown 또는 텍스트 파일에서 계획 가져오기
- 계획을 열어 사이드 패널에서 읽기
- 더 이상 필요 없는 계획 삭제

노트가 저장되거나, 할 일이 체크되거나, 계획이 목록에 표시된 상태로 Context 탭에 돌아와야 합니다. 그것으로 반영되었음을 알 수 있습니다.

## 삭제 및 실행 취소

노트, 계획 또는 저장된 메모리를 삭제하면 몇 초 동안 **실행 취소**가 있는 토스트가 표시됩니다. 그 시간이 지나야 항목이 완전히 제거됩니다.

## 에이전트

에이전트는 프로젝트 지식 도구를 통해 동일한 노트, 할 일, 계획을 읽고 업데이트합니다. 에이전트에게 결정을 기록하거나, 할 일을 추가하거나, 완료로 표시하거나, 계획을 최신 상태로 유지해 달라고 요청하면 변경 사항이 패널에 즉시 표시됩니다. 에이전트가 만든 노트는 에이전트에서 온 것으로 표시됩니다. 에이전트가 당신을 위해 계획을 작성하면 눈앞에 계획을 열어 줄 수 있으며, 거기서 읽고, 줄에 댓글을 달고, 세션으로 보낼 수 있습니다. 계획은 일반 Markdown 파일이므로 에이전트는 다른 파일처럼 읽고 편집합니다. 계획은 단계들의 짧은 체크리스트로 시작해 구현하면서 각 항목을 체크하고, 열린 계획은 몇 초 안에 변경 사항을 반영하므로 미리보기에서 작업이 얼마나 진행됐는지 볼 수 있습니다.

에이전트는 워크트리를 포함해 자기 세션이 속한 프로젝트에서 작업합니다. 입력하는 동안 에이전트가 노트나 계획을 변경하면, 입력한 내용이 에이전트의 변경 위에 저장됩니다. 에이전트는 노트나 계획을 통째로 교체할 때 읽은 텍스트를 함께 보내도록 요청받습니다. 그 사이에 변경됐다면 쓰기가 거부되고 에이전트가 다시 읽습니다.

이 도구는 기본적으로 켜져 있습니다. **Settings → General → OpenChamber Tools**에서 **Project knowledge tool**로 끌 수 있습니다. 다른 OpenChamber 도구와 마찬가지로, OpenChamber가 자체 OpenCode 서버를 실행할 때만 제공되므로 외부 서버나 VS Code 확장에서는 사용할 수 없습니다.
