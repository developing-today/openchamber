# Instalação

Escolha o app que combina com o seu jeito de trabalhar:

- app de desktop para macOS, Windows e Linux
- app web executado pela CLI, que você pode instalar como um app de celular (um PWA)
- extensão para VS Code, também para Cursor, Windsurf e Trae
- apps móveis para iPhone e Android, em beta pública

## Desktop

Baixe a versão mais recente na [página de download](https://openchamber.dev/download/) ou no [GitHub Releases](https://github.com/openchamber/openchamber/releases/latest) e abra. Para Linux há `.deb`, `.rpm` e AppImage.

O app de desktop traz a própria cópia do [OpenCode](https://opencode.ai) (o agente de IA para código em que o OpenChamber roda), então não há mais nada para instalar.

## Web + PWA

O app web precisa do [OpenCode](https://opencode.ai) e do Node.js 24.14 ou mais recente na máquina onde ele roda.

```bash
curl -fsSL https://raw.githubusercontent.com/openchamber/openchamber/main/scripts/install.sh | bash
openchamber --ui-password be-creative-here
```

Abra a URL que a CLI mostra (normalmente `http://localhost:3000`). Você deve ver a lista de sessões do OpenChamber. Para deixá-lo à mão, use a opção "Instalar" na barra de endereço do navegador e adicione-o como app.

## VS Code

Instale o OpenChamber pelo [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.openchamber). Cursor, Windsurf e Trae instalam pelo [Open VSX](https://open-vsx.org/extension/FedaykinDev/openchamber). A extensão precisa do [OpenCode](https://opencode.ai) instalado; depois, a visualização do OpenChamber abre na barra lateral.

## Celular

Instale o app de iPhone pelo TestFlight ou o app de Android pela versão mais recente e depois pareie-o com o seu computador. [Apps Móveis e PWA](/pt-br/mobile/) mostra os dois passos.

## Nix

No NixOS, ou em qualquer Linux com Nix, o flake no repositório do OpenChamber compila os mesmos aplicativos:

```bash
nix run github:openchamber/openchamber        # servidor web em http://localhost:3000
nix run github:openchamber/openchamber#gui    # aplicativo desktop
```

O flake também expõe `packages.openchamber` e `packages.openchamber-desktop`, e um módulo systemd `nixosModules.openchamber` com `host`, `port`, `openFirewall` e `uiPasswordFile`. O arquivo de senha é lido pelo `LoadCredential` do systemd, então um segredo de propriedade do root com permissão 0400 funciona com o usuário dinâmico padrão.

As atualizações passam pelo flake. A CLI do OpenCode empacotada está com o atualizador no aplicativo desativado, porque um caminho da loja do Nix não pode se atualizar sozinho; para atualizar, baixe o flake e compile novamente.
