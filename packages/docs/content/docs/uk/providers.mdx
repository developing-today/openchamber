# Провайдери, моделі та агенти

Перш ніж OpenChamber зможе щось робити, до нього треба підключити щонайменше одного AI-провайдера. Ця сторінка охоплює підключення провайдера, вибір моделі та налаштування агентів.

## Підключення провайдера

1. Відкрийте **Settings → Providers**.
2. Відкрийте меню **Add provider** й оберіть провайдера, який ще не підключений, або оберіть **Інше / Власний** для ендпоінта, сумісного з OpenAI.
3. Увійдіть одним із двох способів, залежно від провайдера:
   - **API key** — вставте свій ключ і збережіть.
   - **Sign-in (device flow)** — OpenChamber показує посилання й короткий код. Відкрийте посилання, введіть код і підтвердьте. OpenChamber завершить підключення самостійно.

### Власні та інші провайдери

Для шлюзів, університетських LLM, Ollama, LiteLLM та подібних API, сумісних з OpenAI:

1. Оберіть **Інше / Власний** у списку провайдерів.
2. Введіть ID провайдера, показувану назву, базову URL-адресу (`http://` або `https://`), ключ API або `{env:VAR_NAME}` і щонайменше один ID та назву моделі.
3. За бажанням перелічіть рівні міркування моделі, наприклад `low, medium, high`. Кожен рівень з'являється у виборі варіантів моделі в чаті, як і для вбудованих провайдерів.
4. За бажанням додайте заголовки запитів.
5. Збережіть. OpenChamber записує блок провайдера в конфігурацію OpenCode і зберігає ключ в автентифікації OpenCode, якщо ключ введено буквально, або фіксує посилання `{env:VAR}`.
6. Щоб змінити наявного власного провайдера, відкрийте його й оберіть **Редагувати**.

Власні провайдери потребують ключа API або `{env:VAR_NAME}`, перш ніж показуватися як повністю підключені. Без облікових даних моделі можуть з'являтися, але виклики в чаті завершаться помилкою.

Коли провайдер показано як підключений, його моделі стають доступними в чаті.

Щоб відключити, відкрийте провайдера й виберіть видалення його входу.

## Вибір моделі

Модель ви обираєте там, де працюєте:

- у чаті використовуйте перемикач моделей у рядку повідомлення, щоб задати провайдера й модель для цієї сесії
- для кожного агента задайте модель за замовчуванням (нижче)

## Налаштування агентів

Агент — це іменоване налаштування: модель, характер та те, що йому дозволено робити.

1. Відкрийте **Settings → Agents**.
2. Оберіть агента або створіть нового.
3. Відредагуйте будь-що з:
   - **description** — для чого призначений агент
   - **model** — його модель за замовчуванням
   - **temperature** — наскільки креативними є його відповіді
   - **prompt** — постійні інструкції, яких він завжди дотримується
   - **tool rules** — якими інструментами він може користуватися

## Де зберігаються ваші входи

Входи провайдерів зберігає OpenCode, а не OpenChamber, тож вони спільні з CLI OpenCode. Якщо ви задаєте одного провайдера в кількох місцях, перемагає найбільш специфічне налаштування: налаштування для проєкту має пріоритет над вашим персональним.
