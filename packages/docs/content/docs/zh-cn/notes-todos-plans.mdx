# 项目笔记、待办与计划

每个项目都有自己的草稿空间，用于存放笔记、待办列表和已保存的计划。它们属于项目，而不属于任何单个会话，因此当你在会话之间切换时它们会一直保留。在右侧边栏的 **Context** 标签页中可以找到它们（在移动端是一个专用标签页）。

## 笔记

一个自由格式的笔记框，用于记录任何你想记住的关于项目的内容。它会在你输入时自动保存。

## 待办

一个简单的清单。添加条目、勾选完成、通过拖动重新排序，并清除已完成的条目。

每个待办都有一个 **send** 菜单，让你可以把它交给智能体：

- 发送到当前会话
- 用它开启一个新会话
- 用它开启一个新的 [worktree 会话](/zh-cn/worktrees/)（仅当项目是 git 仓库时）

## 计划

一个用于将较长的计划保存为文件的地方。你可以：

- 从 Markdown 或文本文件导入计划
- 打开一个计划在侧面板中阅读
- 删除你不再需要的计划

完成后你应该会回到 Context 标签页，并看到笔记已保存、待办已勾选或计划已列出 — 这就是它生效的标志。

## 删除与撤销

删除笔记、计划或已保存的记忆时，会显示一个带 **撤销** 的提示，持续几秒钟。只有当这段时间结束后，该条目才会被彻底删除。

## 智能体

智能体通过项目知识工具读取和更新相同的笔记、待办和计划。让智能体记录一个决定、添加一项待办、勾选完成一项或保持计划最新，变更会立即出现在面板中。智能体创建的笔记会被标记为来自智能体。当智能体为你编写计划时，它可以在你面前打开该计划，你可以阅读它、评论具体的行，并将其发送到会话。计划是纯 Markdown 文件，因此智能体像对待其他文件一样读取和编辑它们。它们以一份简短的步骤清单开始计划，并在实施时逐项勾选；打开的计划会在几秒内同步变更，因此其预览能显示工作进展到哪一步。

智能体在其会话所属的项目上工作，包括 worktree。如果你正在输入时智能体更改了笔记或计划，你输入的内容会覆盖智能体的变更并保存。智能体在整体替换笔记或计划时，需要附上它读取的文本；如果文本此后已更改，写入会被拒绝，智能体会重新读取。

该工具默认开启。在 **Settings → General → OpenChamber Tools** 中使用 **Project knowledge tool** 将其关闭。与其他 OpenChamber 工具一样，它仅在 OpenChamber 运行自己的 OpenCode 服务器时可用，因此外部服务器或 VS Code 扩展中没有它。
