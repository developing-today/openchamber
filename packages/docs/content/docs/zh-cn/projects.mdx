# 项目

项目是你计算机上一个由 OpenChamber 追踪的文件夹 — 通常是一个代码库。切换项目会切换智能体工作所在的文件夹，以及该项目的会话和设置。

## 添加项目

你可以从几个地方添加项目：

- 命令面板中的 **Add project** 条目
- 会话侧边栏顶部的 **+** 按钮
- 选择目录时的文件夹浏览器

将它指向一个文件夹，OpenChamber 就会记住它。名称来自文件夹；你之后可以更改它。

## 切换项目

从侧边栏选择一个项目使其成为活动项目。一切 — 会话、git、笔记 — 都会跟随你打开的项目。

## 让项目易于辨认

打开 **Settings → Projects** 为项目设置自定义名称、颜色或图标。OpenChamber 会尝试自动查找图标 — 参阅 [项目图标](/zh-cn/project-icons/)。

> 在 VS Code 中，OpenChamber 始终使用你打开的文件夹作为唯一的项目，因此没有要添加或切换的内容。Projects 设置页面在那里是隐藏的。

## 将会话分组到文件夹

在侧边栏的 **Tree** 视图中，右键单击一个会话，选择 **Move to folder** 将其放入文件夹，或选择 **New folder...** 新建一个。文件夹属于项目根目录或某个 worktree，文件夹行带有重命名和删除按钮。删除文件夹会保留其中的会话；它们会回到项目中。

文件夹存储在 OpenChamber 服务器上，因此连接到同一服务器的一切都会显示相同的文件夹：登录到该服务器的另一台计算机、Web 应用和手机。在一台设备上的更改会在一秒内出现在其他设备上，无需重新加载。每个服务器都有自己的文件夹。哪些文件夹处于折叠状态保留在各自设备上。

手机在它的 Tree 视图中显示文件夹，但无法更改它们。请在桌面端或 Web 应用中移动会话。

当设备从将文件夹保留在各设备上的版本更新后首次连接时，它的文件夹会被添加到服务器的文件夹中。与服务器已有的文件夹同名且位于同一位置的文件夹会并入其中，其会话也会随之移动；不会丢弃任何内容。服务器已经归档的会话会保留在服务器的文件夹中。

删除会话会将其从所在文件夹中移除，关闭项目会删除其文件夹。在 VS Code 中，文件夹保留在扩展内，不会共享。

## 项目环境

如果项目的工具来自 direnv、devenv 或 Nix shell，Git 钩子、终端和[项目操作](/zh-cn/project-actions/)自己是找不到它们的。打开 **设置 → 项目**，选择项目，然后在 **环境** 下：

- 添加只有这个项目需要的变量
- 或者设置一条输出这些变量的 **环境命令**，例如 `direnv export json` 或 `devenv print-dev-env --json`

命令在项目文件夹中运行；对于 worktree，则在该 worktree 自己的文件夹中运行。当你提交、打开终端或运行操作时，如果上次运行已过去几分钟，它会重新运行；点击 **重新运行** 会立即运行。仅仅打开项目并不会运行它。输入框下方会显示上次运行添加了多少个变量，或者失败的原因。运行失败时不会添加任何变量，Git 和终端照常工作。

这些变量会传给 Git、终端和项目操作，并叠加在 **设置 → 通用 → 环境变量** 中的变量之上（参阅[环境变量](/zh-cn/environment/#供-opencodegit-和终端使用的变量)）。OpenCode 用一个进程服务所有项目，所以它拿不到项目变量：智能体需要的变量请放在通用列表里。

这条命令只能由你自己设置。它不会从仓库中读取，所以克隆下来的仓库无法让 OpenChamber 运行任何东西。
